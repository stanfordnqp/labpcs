How this works…
  • Each PC runs a scheduled task every 5 minutes, starting at boot, even with nobody logged in.
  • It reads what's running, free RAM, disk and GPU use, and sends that to a small Google script.
  • Bookings live in three Google Calendars, one per PC, which the same script reads.
  • This page asks the script for the latest status and bookings every 5 minutes.
  • If a PC stops reporting, its status shows as stale after 15 minutes.
